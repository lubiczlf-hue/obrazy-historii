## Publikacja

GitHub Pages, osobne repozytorium lubiczlf-hue/obrazy-historii. Każdy push na main publikuje katalog dist przez .github/workflows/pages.yml. Domena: dist/CNAME. Pozostałe repozytoria nie są częścią tej konfiguracji.

## Aktualizacja treści

- Strona główna: dist/index.html
- Styl: dist/styles.css
- Aktualności: dist/news.js; każdy wpis ma lokalną miniaturę i opis alternatywny.
- Polityka prywatności: dist/polityka-prywatnosci.html
- Regulamin: dist/regulamin.html (treść na stronie, bez PDF).
- Logo: dist/assets/logo-black.png; biały wariant stopki przez CSS.
